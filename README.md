📌 Descrição

Este projeto implementa o controle de um servo motor utilizando o Raspberry Pi Pico W. O código foi desenvolvido em C e simulado no Wokwi.

🎯 Objetivos

Controlar um servo motor via PWM utilizando o Raspberry Pi Pico W.

Integrar um LED indicador ao sistema.

Simular e testar o projeto no Wokwi antes da implementação física.

🛠️ Componentes Utilizados

- Raspberry Pi Pico W

- Servo Motor

- LED Azul

- Resistor de 330Ω

🔗 Diagrama de Conexões (Wokwi): como consta no arquivo diagram.json do repositório.
